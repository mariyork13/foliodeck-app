# Переезд сайта с Vercel на Timeweb App Platform

Статус: **шаг 0 готов, ветка `migrate/timeweb-apps`; дальше шаг 1** (2026-11-03).

## Зачем

1. **Vercel поставил аккаунт на паузу** 2026-11-03: бесплатный тариф Hobby,
   превышен лимит Fast Origin Transfer (15,4 из 10 ГБ). Пауза до 2026-12-03.
   Pro за $20/мес владелица платить не хочет. Причины перерасхода исправлены
   в коммите e68d019, но лимиты Vercel остаются риском.
2. **Мобильные операторы РФ режут адреса Vercel**: с сотовых данных сайт
   не открывается (см. [`deploy/ru-proxy.md`](../deploy/ru-proxy.md)). После
   переезда этот черновик прокси больше не нужен.
3. Сайт тоже окажется в РФ, а не только данные. Это лучше для 152/242-ФЗ.
4. Один счёт в Timeweb, оплата российской картой.

## Что есть сейчас

| Часть | Где | После переезда |
|---|---|---|
| Приложение Next.js 16 (`next build` / `next start`) | Vercel, проект `mariyork/foliodeck-app` | **Timeweb App Platform** |
| БД PostgreSQL 17 | Timeweb, Москва | без изменений |
| Картинки | Timeweb S3, бакет `foliodeck-media` | без изменений |
| Домен `foliodeck.pro` | reg.ru, A → 216.198.79.1 (Vercel) | A/CNAME → Timeweb |
| Внутренняя база «Дизайн тащит» + админка | `dizain-tashchit-baza.vercel.app` | новый адрес, например `base.foliodeck.pro` |

Привязок к Vercel в коде нет: нет `vercel.json`, нет пакетов `@vercel/*`.
Хранилище картинок уже S3, кэш — встроенный ISR Next.js. По
`node_modules/next/dist/docs/01-app/02-guides/self-hosting.md`, ISR и
`revalidatePath` работают сами при **одном** инстансе `next start` с
постоянным диском. Поэтому приложение должно работать **в одном экземпляре**,
без автомасштабирования.

## Кто что делает

Владелица — не программист. Её шаги — клики в панелях и вставка готовых
значений, **по одному шагу с точными подсказками**. Код, проверки и
подготовку значений делает Claude. Изменения в Vercel env и оплаты делает
только владелица.

- [x] Ветка `migrate/timeweb-apps`.

- [x] Dockerfile не нужен. В пресете Next.js у Timeweb есть переключатель
      **SSR**: с ним приложение работает как backend (свой сервер, Node 20/22/24,
      `npm start`). Постоянного диска нет: кэш ISR живёт в контейнере и
      сбрасывается при каждом деплое. Это нормально, страницы просто
      пересоберутся. Несколько доменов на одно приложение можно; редирект
      `www` → корень настраивается в «Настройки веб-сервера» (тип `host`).
      Перед приложением стоит Caddy, он передаёт `X-Forwarded-For`.

## Риски и что проверить

- **Telegram из РФ.** `api.telegram.org` из российских дата-центров может
  работать с перебоями. Проверить на шаге 3. Если не работает — уведомления
  о заявках на почту или через прокси.
- **Один сервер.** Нет мировой сети Vercel: из-за рубежа чуть медленнее, VPN
  не нужен. При падении сервера сайт недоступен, пока Timeweb его не
  перезапустит.
- **Память.** `next build` может не уложиться в 1 ГБ RAM. Тогда тариф выше
  или сборка в GitHub Actions.
- **Цена.** Точную стоимость тарифа показать владелице **до** оплаты.
